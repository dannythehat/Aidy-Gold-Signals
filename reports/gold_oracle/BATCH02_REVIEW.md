## Source blockers proved and preserved

- **S024:** full-series swing clustering changes zones and earlier entries at tested prefixes in all three years. No repaired result replaces the native one.
- **S022:**2024 prefix instability. Before the market-open bar arrives the original ORB falls back to the first bars of that day; appending the market-open bar selects a different range and removes early entries. A minimal original-source regression proves this mechanism. Its separate close-confirmation/retroactive-level fill defect remains.
- **S012:** changing only the final H1 close in an H4 interval changes the earlier H4-open timestamp bias. Original native function regression proves lookahead. H1 bias joins and FVG code also differ from the prose; no performance invented.
- **S082:** valid low<=high means high>=level OR low<=level always holds. Original function discards every old level after intervening bars; logically zero signals, not a negative economic grade. No silent OR-to-AND repair.
- **S014 Python:** same-bar sweep below prior20 low plus bullish gap above high[i-2] are mutually exclusive; short symmetric. Original function test returns no setups. Catalogue S014 also has a different Pine implementation, so this does not reject every implementation under that title.
- **S016:** exact strategy-class AST identity after removing only params. Entry20/risk1% versus entry95/risk2%; exit20/ATR40/target4ATR shared. This is one within-ID parameter family, not two original independent systems. Full program identity not asserted. Original loader uses synthetic high/low, so original published account figures are not authentic spot OHLC evidence.
- **S018:** two called helpers absent from the entire original MQL file and no includes. Native compiler unavailable; compile failure inferred, not falsely reported as a compiler run.
