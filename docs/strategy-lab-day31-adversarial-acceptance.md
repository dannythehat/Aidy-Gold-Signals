# Day 31 — Adversarial reporting, independent numeric parity and review signoff

**Locked scope:** B08 Day31 "Bad inputs, zero trades, source mismatches, misleading claim checks". Full stage PASS additionally calls for **independent human review and report parity**. The human signoff is deliberately NOT fabricated or completed by software; the technical build produces the real downloadable review packet, including an unsigned human checklist for independent approval.

## Actually implemented

- `src/aidy/strategy_lab_report_adversarial.py` implements an **independent second-path verifier** over the real Day30 PDF/CSVs/JSON and source provenance. Every field of all original journal trade CSV records (ID, direction, entry and exit timestamps, gross, fees, net, original run/journal SHA) and every field of all three candidate/control cost stress records (scenario, tick count, multiplier, commission, slippage, funding, gross, net, comparison, policy hashes) is compared to original frozen source. Numeric figures use exact `Decimal`. The old Day30 verifier checked headlines but did not verify all of these fields; the new verifier closes that integrity gap.
- Independently parses the real report PDF with `pypdf` to check section text, source run identity, trade accounting, all five day/week/month/year/all-time money views, 3 source cost scenario values, all nine-factor labels and weights, all original source hashes and absence of common forged "live profits" marketing claims. Even if an attacker appends a new bogus PDF page and **recalculates the manifest SHA**, the new verifier rejects the forbidden claim.
- Explicit empty-trade evaluation returns `NO_TRADES_INSUFFICIENT_EVIDENCE` and **null** win rate, expectancy, Sharpe and nine-factor score: not invented zero or profitable historical performance. The fixed original four-trade reference builder also rejects attempts to remove trades while retaining positive cash totals.
- `tests/test_strategy_lab_day31_adversarial.py` carries parametric adversarial tests, including changed cost fee and spread fields with re-signed manifest SHA, changed trade ID/direction/opening time, bogus live profit page, missing original file, forged customer join/paper account/Elite 20 P&L, fake 100/100 score, removed provenance and empty positive-P&L trade history. Crucially tests demonstrate that selected tamper cases would **pass the prior Day30 headline verifier**, yet are rejected by Day31 independent full-field parity. Failures are an expected acceptance condition; do not mask or skip negative tests.
- `scripts/strategy_lab/day31_adversarial_report_acceptance.py` first runs Day30's genuine read-only historical XAUUSD BigQuery twice, rebuilds the actual complete four-page PDF/CSVs/charts from Day29 original canonical JSON and live original-sample synthetic SQLite cash journal, executes **16 adversarial mutations** on independent cloned real exports, and writes `artifacts/strategy_lab/day31_adversarial_acceptance.json` with original input SHA/run identity and each attack's explicit rejected result. Also saves **`artifacts/strategy_lab/day31_human_review_pending.md`** with genuine original source hashes and a human-readable checklist, mandatory PDF page/CSV visual examination and UNSIGNED reviewer name, date and decision slots.
- GitHub Action `.github/workflows/strategy-lab-day31-adversarial.yml` runs strict Ruff/compilation, all Day24–30 prior regressions, Day31 new attacks, new BigQuery original live read-only replay + PDF build, exact 16-for-16 attacks blocked and passes only if the **human review is truthfully still unapproved**. Uploads the whole audited report bundle and reviewer checklist as real GitHub Actions artifacts.

## Important distinction

**Software acceptance** proves computational rejection and source integrity. It CANNOT certify an independent human has looked at the PDF, that the styling/visual warnings are sufficiently conspicuous, or that the real owner approved B08. The stage's separate **human review** remains **PENDING** until someone independently examines the actual PDF+CSV+graphs, reconciles financial content and source links, records reviewer identity/time and signs off. Never invent or self-sign that requirement.

The original source still combines Day24/25 **INTERNAL SYNTHETIC ledger and cost scenarios** with independently sourced 2025 retrospective BID-only historical gold directional research. None of these are verified profitable original-market XAUUSD strategies, forward paper production account results, an authorised GoldThinker named system or the GoldThinker Elite 20 combined account. We continue to withhold unqualified nine-factor numeric confidence and publication/connection rights. Source SHA256 hashes alone are tamper evidence, not proof of independently authenticated arbitrary customer materials.
